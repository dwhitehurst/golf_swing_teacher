# Golf Swing Teaching Viewer v2

Open `index.html` directly in your browser.

No server, Tomcat, Node, Python, or VS Code is required.

## New in v2

- Drawings / Photos toggle
- Drawing images cropped much tighter to reduce wasted black background
- Drawing coordinate system preserved (the ball is already registered almost perfectly across the original frames)
- Previously aligned photographic Face-On set included
- P1–P10 Face-On and Down-The-Line teaching notes harvested and condensed from the supplied screen recording
- Numerical-angle-heavy material intentionally minimized
- One synchronized crossfade slider for both views

## Controls

- Drag slider: continuous crossfade
- P1–P10 buttons: exact checkpoints
- Left/right arrows: fine movement
- P: Play/Pause
- S: snap to nearest P
- R: reset
